# 璃瞳 (LumiIris Studio) — 测试版更新源仓库

本仓库为 **璃瞳 (LumiIris Studio)** 的内部测试与灰度发版通道，独立于正式发版仓库 `SuRanHF/lumiiris-releases`。

## App 内直连测试更新方法

1. 打开手机上的 **璃瞳 (LumiIris Studio)** → 进入 **设置** 页
2. 在 **「Gitee / GitHub / version.json 更新源地址」** 输入框填入：
   ```
   https://github.com/SuRanHF/lumiiris-test-releases
   ```
3. 点击 **保存地址** → 点击 **立即检查更新**，即可直接下载安装测试版 APK
4. 测试完成后可将更新源改回正式通道（`https://gitee.com/wanoujj/lumiiris-releases` 或 `https://github.com/SuRanHF/lumiiris-releases`）
